# Sistema web de soporte tecnico universitario
1. Copiar la carpeta `soporte_tecnico` a `htdocs` de XAMPP.
2. En phpMyAdmin importar `sql/soporte_db.sql`.
3. Abrir http://localhost/soporte_tecnico/index.php
Modulos: usuarios.php / equipos.php (1), solicitudes.php (2), seguimiento.php / atender.php (3).
